Entry for the make.fun bounty [Make the best flight game](https://make.fun/c/best-flight-game-20261126-0057).

Fly a canvas-and-wood mail plane along the Caspian coast: thread amber rings over rice
terraces, drop mail sacks on tea villages, ride out sea gusts and a storm, and put her
down gently on lamp-lit strips. Six sorties, stars and credits, and an upgrade draft
after every landing.

## Controls

- Arrow keys: pitch and bank (mouse hold also steers)
- W / S: throttle
- Space: drop a mail sack
- M: mute, P: back to the campaign map

## Run

Serve the `game/` folder with any static server and open `index.html`, or hand the entry
in with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
